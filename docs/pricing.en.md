## How pricing works

| Item | Effect |
| --- | --- |
| Number of seats | Determines the price (n × €19) |
| Requests per seat | **Unlimited** (fair use 60/min) |
| Data state | Included — daily updates |
| Coverage | Included — full corpus |

One seat = one person OR one standalone API key. API keys assigned to a person don't cost an extra seat.
